# v3.2.5 — Free historical research data integration

The application now supports a **free, explicitly limited** historical data pathway: observed Yahoo price, volume, dividend-adjusted price history for named current tickers, and optional vintage SEC companyfacts (filed-date aware). The ranking page and daily prediction job use dated SEC factors when available. A local archive builder, hash verification, diagnostics, and optional strictly aligned older history reuse are included. No delisting payoff is invented and no current-symbol archive is misrepresented as a historical constituent universe.

See `FREE_HISTORICAL_DATA_v3.2.5.md` for exact setup commands and limitations.

Live service accessibility and forward predictive advantage have NOT been demonstrated by the offline tests.
